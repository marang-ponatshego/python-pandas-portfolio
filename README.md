## Notes

- Notebooks use **local file paths** in `pd.read_excel(...)` and
  `pd.read_csv(...)`. Update them to your own paths before running.
- The notebooks are Jupyter (`.ipynb`) files and render on GitHub
  with code, outputs, and charts visible.
- Raw data files are included where applicable so the notebooks can
  be reproduced.

## About

This is a portfolio project — the goal is to demonstrate hands-on
Python data skills rather than analyze a live production dataset.
The three notebooks follow a common structure: load, inspect, clean,
transform, visualize.
